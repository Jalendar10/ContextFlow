# ContextFlow interview skill templates

Choose one role template and import it in **Agents & skills → Import SKILL.md**. Add the résumé, JD and invitation email separately; these files do not contain candidate facts. Select Interview response style and an answer model. Generate interview skills and an answer guide if you want a tailored version, review the result, then save the agent. Generation replaces the skills text, so keep the downloaded template if you want to restore it.

Files: FDE, Data Engineer, Software Engineer, AI/ML Engineer and Solutions Architect.

For a live session, select the saved agent. Enable **Use previous transcript** to include recent speech from both audio sources. **Ask agent · latest request** targets the latest interviewer passage; individual Ask agent controls target their own passage. Microphone speech supplies context and assessment evidence.

Templates define behavior; they do not grant tools, run scripts, infer private interviewer intentions or establish candidate experience. All are below ContextFlow’s 16 KB skill import limit. Review generated guidance before use and follow the interview’s rules on assistance.
